# MetamorphX

Simple C project structure:

```text
MetamorphX/
├── README.md
├── .gitignore
├── Makefile
├── include/
│   ├── evasion.h
│   └── polymorph.h
├── src/
│   ├── evasion/
│   │   └── main.c
│   └── polymorph/
│       └── main.c
└── build/
```

## What Goes Where

- `Makefile`: build commands
- `include/`: header files
- `src/evasion/`: source files for the evasion program
- `src/polymorph/`: source files for the polymorphic program
- `build/`: compiled files and binaries
